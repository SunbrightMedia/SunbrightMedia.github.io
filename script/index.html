Expression reference

Every field is a JavaScript expression, evaluated once per element of the modifier's level (once per point for Displace).

Variables
i index within the level · n count · u = i/(n−1), 0..1
t time (s) · size font size
x y element centre (point position for Displace) · w h bounding box size
li wi gi ci line / word / glyph / contour index this element belongs to
pi point index in contour · ctrl 1 for curve handles · k global point index · ch character code

Functions
All of Math without the Math. prefix (sin cos abs pow min max PI …), plus rnd(a,b) 0..1 stable random · noise(x,y) −1..1 · fbm(x,y,oct) · clamp lerp mix smoothstep fract tri saw sq pulse ease deg · hsl(h,s,l,a) rgb(r,g,b,a) · TAU

Colour fields accept plain text too (#f80, none, red).

Spatial modifiers (Warp, Nature) sit on the stage. Drag the shape to move it and the round handle to resize and rotate it. Their fields are expressions too, evaluated once per frame (t and size are available), e.g. x = 380 + sin(t)*300.
