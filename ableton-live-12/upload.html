Upload a Live project

Sends your zipped project folder to the site's GitHub repository in parts, so it can be turned into a web version. Nothing on the live site changes.

1. Connect to GitHub (once on this device)

GitHub only accepts uploads made with a key from your account. This page keeps the key on this device and sends it only to GitHub.

  1. Open GitHub's key page. Make sure repo is ticked, then press Generate token at the bottom.
  2. Copy the key GitHub shows (it starts with ghp_) and paste it here:

Connected as .

2. Choose the zipped project

Connect and choose a file, then press Start.
